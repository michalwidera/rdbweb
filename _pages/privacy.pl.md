retractordb.com to statyczna strona hostowana na GitHub Pages. Nie
korzysta z żadnej analityki, żadnych reklam i nie ustawia własnych
plików cookie.

## Co zbiera GitHub

Ponieważ strona jest serwowana przez GitHub Pages, standardowe logi
serwera WWW (adres IP, żądana strona, user agent, znacznik czasu) są
zbierane przez GitHub jako dostawcę hostingu. Szczegóły dotyczące tego,
co i jak długo loguje GitHub Pages, znajdziesz w
[Oświadczeniu o prywatności GitHub](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)
(w języku angielskim).
