retractordb.com is a static site hosted on GitHub Pages. It runs no
analytics, no advertising, and sets no cookies of its own.

## What GitHub collects

Because the site is served by GitHub Pages, standard web server logs
(IP address, requested page, user agent, timestamp) are collected by
GitHub as the hosting provider. See
[GitHub's Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)
for details on what GitHub Pages logs and for how long.
